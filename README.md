# 🌀 颱風來襲

在西北太平洋的真實地圖上畫出颱風路徑，讓颱風在溫暖海面成長，再撲向東亞各地的網頁遊戲。

**線上遊玩：** https://battlefield6348.github.io/typhoon-attack/

## 玩法

1. 從菲律賓東方的「颱風生成區」（虛線框）按住拖曳，畫出颱風路徑。
2. 按「發動颱風」，颱風沿路徑前進，強度隨環境即時變化。
3. 兩種模式：
   - **🎯 任務模式**：摧毀 3 座指定城市（大城市耐久度高，需要夠強的颱風），三星評價：完成任務／成長為強烈颱風／8 天內完成。
   - 可自己幫颱風命名；地圖下方的新聞跑馬燈會即時播報颱風動態與各地災情。
   - **🗺️ 自由模式**：颱風掃過的省／縣市依當地風速與停留時間累積災情（輕微 → 毀滅性），以災損指數計分。

## 環境影響

| 環境 | 效果 |
|---|---|
| 溫暖海面（≥ 26.5°C） | 增強，海溫越高上限越高（黑潮、西太平洋暖池特別有利） |
| 冷水（< 26°C） | 減弱 |
| 垂直風切（風切圖層的紫色區域） | 減弱，北方西風帶風切較強 |
| 陸地／高山 | 減弱，台灣中央山脈等高山減弱更快 |

## 動態天氣與衛星雲圖

- 預設畫面為衛星雲圖風格，可切換「衛星雲圖／海溫／風切／駛流」圖層（鍵盤 1～4）。
- 風切系統會移動、生成與消散，暖／冷水渦旋緩慢漂移，西風帶南緣會南北擺動。
- 畫路徑時地圖顯示颱風抵達游標處那天的預報，也可拉動時間軸預覽；實際天氣與預報有誤差，越遠越不準。

## 駛流與防颱

- **駛流**：颱風被大氣氣流推著走。太平洋高壓南側往西吹、西風帶往東吹，高壓西緣會把颱風往北帶。路線依速度著色：藍＝順著駛流很快、白＝正常、黃＝偏慢、紅＝逆著駛流很慢（耗壽命又攪冷海水）。按 4 可看駛流圖。
- **防颱準備**：颱風接近時各國發布警報、展開防颱，城市外圈藍弧為準備進度，準備完成時損害減少 40%。拖越久，打得越不痛。

## 限制

- **壽命 12 天**：路線長度依預報駛流換算成天數，逆著駛流走很快就會用完。
- **冷水尾跡**：颱風會攪動海水使海溫下降，在同一片海域繞圈只會越來越弱。
- **生成區**：只能在熱帶海面生成。

## 開發

純 HTML / CSS / JavaScript，無需建置，直接開啟 `index.html` 即可。

地圖資料：[Natural Earth](https://www.naturalearthdata.com/)（公有領域），`data/land.js` 為 1:50m 陸地、`data/regions.js` 為 1:10m 省／縣市級行政區。
